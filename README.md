# Logika II — materiały do egzaminu

Interaktywne notatki i quizy do egzaminu z Logiki II (kognitywistyka).

**Otwórz stronę:** [GitHub Pages link po wdrożeniu]

## Zawiera
- 29 notatek koncepcyjnych (definicja + przykłady + sprawdź się)
- Quizy zamknięte do każdego rozdziału (143 pytania łącznie)
- Aktywne ćwiczenia w formacie pytań otwartych z egzaminu
- Sekcje: Ziembiński rozdz. I–XI + Chalmers rozdz. I–IV

## Pamięć
Zaznaczenia (✓) są zapisywane w `localStorage` przeglądarki i przetrwają zamknięcie karty.
Czyszczenie danych przeglądarki/cookies usunie postęp.
